## About Me

I build **AI agents that take real actions**, not just generate answers.

My focus is **tool-calling agents, MCP servers and the backend systems behind them**: the APIs agents call, the state they carry between steps, and the guardrails that keep them safe.

I care most about the parts that break in production: **retries that create duplicates, timeouts that look like failures, malformed tool output, and agents that pass a demo but fail on real data.** Good agents are mostly good tools, retries, state and error handling.

Based in **Chennai, India** · open to remote collaboration.
